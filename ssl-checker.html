Frequently Asked Questions

How does this SSL checker work?
This tool uses the public SSL Labs API (no key required) via CORS proxy to get real SSL/TLS grades, protocols, ciphers, and vulnerabilities. It also fetches real security headers.
What is an SSL Labs grade?
SSL Labs is the industry standard for SSL/TLS testing. Grades range from A+ (best) to F (failing). A or A+ means your SSL is properly configured.
Why do some checks show "unknown"?
Some servers block CORS or SSL Labs is still scanning (first scan can take 30-60 seconds). We show what we can fetch.
Is my data private?
Yes. Your URL is sent to SSL Labs API (public service). No personal data is collected or stored on our servers.
