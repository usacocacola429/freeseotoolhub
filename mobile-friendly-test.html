Frequently Asked Questions

How does this mobile-friendly test work?
Fetches your website's HTML via CORS proxy, then analyzes viewport meta tag, CSS media queries, tap target sizes, font readability, fixed-width elements, and 15+ other mobile SEO signals — all in your browser.
Why does live preview sometimes show blank?
Some websites send X-Frame-Options: DENY or Content-Security-Policy headers that prevent iframe embedding. The analysis still works — only the visual preview is affected.
What is a good mobile score?
Aim for 85+ for excellent mobile-friendliness. Google recommends: viewport meta tag, tap targets ≥48px, readable fonts (≥14px), and no horizontal scroll.
Does Google use mobile-friendliness for ranking?
Yes — since 2021, Google uses mobile-first indexing. Your mobile experience directly impacts search rankings.
