Frequently Asked Questions

Is this free?

Yes, 100% free forever. No signup, no watermarks, no limits.

What is bleed?

Bleed is 0.125" of extra space added to the outside, top and bottom edges so artwork can run to the edge after trimming. KDP requires it if any image or colour touches the page edge.

Is my data safe?

Absolutely. Everything happens locally in your browser. Files never leave your device.

What file formats can I upload?

PDF, JPG, PNG and WebP. Multiple files combine into a single KDP-ready PDF.

What is the minimum page count?

KDP requires a minimum of 24 pages for paperback. The maximum is 828 pages.

How big a file can it handle?

Smart mode works from a few pages up to the full 828-page KDP limit, because pages are copied in a single pass without duplicating fonts or images. What eventually limits you is your own computer's memory — a browser is not a print shop server.
