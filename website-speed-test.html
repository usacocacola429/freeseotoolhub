Frequently Asked Questions

Where does the data come from?
Google PageSpeed Insights API (public) + real fetch for resource analysis. No API key required, but you can provide your own to avoid rate limits.
What are Core Web Vitals?
LCP (loading < 2.5s), INP (interactivity < 200ms), CLS (visual stability < 0.1). Google uses them as ranking factors.
Why does the scan take 30-60 seconds?
Google runs a full Lighthouse audit in real Chrome. First scans are slow; subsequent scans use cache.
Is my data private?
Yes. Your URL is sent to Google PageSpeed Insights API (public). We don't store or log anything on our servers.
