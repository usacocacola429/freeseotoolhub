Frequently Asked Questions

Where does the data come from?
The tool uses Google PageSpeed Insights API (public, no key needed for low volume) plus a real fetch via CORS proxy to analyze page resources, size, and headers.
What are Core Web Vitals?
LCP (loading < 2.5s), INP (interactivity < 200ms), CLS (visual stability < 0.1). Google uses them as ranking factors.
Why does the scan take 30-60 seconds?
Google runs a full Lighthouse audit in real Chrome. First scans are slow; subsequent scans use cache.
Is my data private?
Yes. Your URL is sent to Google PageSpeed Insights API (public service). We don't store or log anything on our servers.
