Frequently Asked Questions

Where does this data come from?
Real data from Google Trends Daily RSS feed. Google publishes the top 20 trending searches per country, updated every few hours. No API key needed — it's public RSS.
Why do some fetches fail?
Google Trends RSS doesn't send CORS headers, so we use multiple public CORS proxies with automatic retry. If all fail, try again in a minute or switch countries.
How often is data updated?
Google Trends Daily RSS updates every few hours. Enable "Auto-refresh" to check every 5 minutes automatically.
Is this really free?
Yes, 100% free. We use public Google Trends RSS — no API key, no signup, no limits.
